# Добавление стендов в портфолио

Этот набор скриптов автоматически добавляет все стенды из папки PhotoForExpo в портфолио Grav, делая их видимыми в админ-панели.

## Что происходит

1. **Скрипт сканирует** папку `/home/ivan/Documents/PhotoForExpo/output folder/`
2. **Создает** отдельные элементы портфолио для каждого стенда
3. **Копирует** все изображения в соответствующие папки
4. **Генерирует** markdown файлы с метаданными
5. **Делает** все стенды видимыми в админ-панели

## Структура результата

```
user/pages/07.portfolio/
├── 01.abat/
│   ├── portfolio-item.md
│   ├── abat1.jpg
│   ├── abat2.jpg
│   └── abat3.jpg
├── 02.agora/
│   ├── portfolio-item.md
│   ├── [изображения стенда]
│   └── ...
└── [остальные стенды...]
```

## Варианты запуска

### Вариант 1: Bash скрипт (рекомендуется)

```bash
# Запустить скрипт
./add_stands.sh
```

### Вариант 2: PHP скрипт

```bash
# Запустить PHP скрипт
php add_stands_to_portfolio.php
```

## После выполнения

1. **Очистить кэш Grav:**
   ```bash
   bin/grav clear-cache
   ```

2. **Проверить админ-панель:**
   - Все стенды будут видны в разделе "Портфолио"
   - Каждый стенд будет иметь свои изображения
   - Можно редактировать метаданные через админ-панель

3. **Редактировать информацию:**
   - Названия выставок
   - Площади застройки
   - Годы проектов
   - Описания и подписи к изображениям

## Особенности

- **Автоматическое именование** изображений
- **Пропуск миниатюр** (файлы с суффиксом `_s`)
- **Генерация метаданных** для каждого изображения
- **Поддержка кириллицы** в названиях папок
- **Создание галерей** для каждого стенда

## Требования

- Bash (для .sh скрипта)
- PHP (для .php скрипта)
- Права на запись в папку `user/pages/07.portfolio/`

## Безопасность

- Скрипты **не удаляют** исходные файлы
- Создают **копии** изображений
- **Не перезаписывают** существующие файлы
- Сохраняют **оригинальную структуру** папок

## Устранение проблем

### Если скрипт не запускается:
```bash
chmod +x add_stands.sh
```

### Если нет прав на запись:
```bash
sudo chown -R www-data:www-data user/pages/
```

### Если изображения не отображаются:
```bash
bin/grav clear-cache
bin/grav clear-images
```

## Результат

После выполнения скрипта у вас будет:
- **106 элементов портфолио** (по количеству папок со стендами)
- **Все изображения** доступны в админ-панели
- **Готовые галереи** для каждого стенда
- **Возможность редактирования** через веб-интерфейс
